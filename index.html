MACHINARA

Industrial AI · Predictive maintenance · 2026

Predictive Maintenance Copilot yang menggabungkan machine health monitoring, prediksi remaining useful life, AI-assisted analysis, dan maintenance ticketing dalam satu workflow dalam industri Oil&Gas.

  • Ringkasan asset health dan critical alert.
  • Anomaly Detection, failure risk prediction, dan estimasi remaining useful life.
  • AI Copilot serta ticketing untuk tindak lanjut maintenance.
System scope and implementation

Scope

Dashboard memusatkan kondisi aset, alert, prediksi, dan ticket maintenance. Modul prediksi membantu membaca indikator kegagalan dan estimasi umur pakai, sedangkan AI Copilot membantu interpretasi kondisi mesin dan rekomendasi tindakan.

Users

Operator atau engineer menggunakan modul monitoring, prediction, copilot, dan ticketing. Fungsi administrasi mengelola pengguna dan konfigurasi sistem.

Implementation

Web application yang terhubung ke service Python/ML untuk predictive maintenance. Pipeline penelitian memakai machine learning, physics-informed guardrail, dan AI layer sebagai copilot.

Output

Health overview, anomaly dan failure analysis, RUL-oriented prediction, AI recommendation, serta maintenance ticket dan schedule.

AMORIS

Education · Daily monitoring · Delivered

Aplikasi monitoring kegiatan religi siswa untuk mengelola aktivitas harian, data sekolah, pemantauan lintas kelas, dan laporan sesuai peran pengguna.

  • Master siswa, guru, pengguna, kelas, dan rolling siswa.
  • Input kegiatan harian, termasuk sholat, hafalan, dan doa.
  • Monitoring kelas dan laporan terpadu untuk sekolah.
System scope and implementation

Scope

Sistem mencakup dashboard monitoring, master data siswa dan guru, user management, input kegiatan harian, pengelolaan kelas, rolling siswa, serta laporan terpadu.

Users

Admin mengelola master data dan pengguna. Guru Agama dapat memonitor lintas kelas serta membantu input kegiatan. Kepala Sekolah menggunakan dashboard dan laporan untuk monitoring. Wali Kelas menginput kegiatan dan melihat laporan kelasnya sendiri.

Implementation

Aplikasi web dengan autentikasi berbasis role, modul master data, form input kegiatan, dashboard monitoring, dan laporan sesuai hak akses.

Output

Rekap aktivitas siswa, status kelas, laporan sekolah, serta kontrol akses yang membatasi data dan tindakan sesuai tanggung jawab pengguna.

Artasy Chicken

Inventory and sales operations · Delivered

Inventory & Invoice Management System untuk mengelola aliran barang dan transaksi dari pembelian, produksi, penjualan, sampai laporan dan dokumen invoice.

  • Master barang, supplier, customer, driver, dan pengguna.

Output

Monitoring stok, histori transaksi, invoice, laporan periodik, dan kartu stok yang membantu penelusuran perubahan persediaan.

Aplikasi Laravel dengan database pasien dan rekam medis, autentikasi, role permission, pencarian, dan reporting.

Output

Data pasien terpusat, catatan pemeriksaan, histori kunjungan, laporan periodik, dan kontrol akses untuk menjaga tindakan penting tetap terbatas.

SPK Pelanggaran Siswa

Decision support · SAW · Delivered

Sistem Pendukung Keputusan yang menggunakan metode Simple Additive Weighting untuk mengelola pelanggaran dan menyusun prioritas penanganan siswa.

  • Master kelas, siswa, kategori, jenis pelanggaran, dan kriteria SAW.
  • Pencatatan pelanggaran serta tindak lanjut pembinaan.
  • Perhitungan SAW, hasil ranking, laporan, dan export data.
System scope and implementation

Scope

Sistem mengelola data siswa dan pelanggaran, menjalankan perhitungan SAW pada periode aktif, lalu menampilkan hasil ranking yang dapat digunakan sebagai bahan prioritas penanganan dan evaluasi.

Users

Admin mengelola master data serta konfigurasi kategori, jenis pelanggaran, dan kriteria. Kesiswaan berfokus pada pencatatan pelanggaran, proses SAW, tindak lanjut pembinaan, dan laporan operasional.

Implementation

Web-based Decision Support System dengan perhitungan SAW, database siswa dan pelanggaran, role-based access, reporting, serta export hasil.

Output

Ranking prioritas penanganan, histori pelanggaran, data tindak lanjut, dashboard ringkasan, dan laporan hasil perhitungan.

SiResik

IoT monitoring · ESP8266 · Laravel · Delivered

Sistem monitoring tempat sampah berbasis IoT yang menghubungkan sensor ultrasonik dan ESP8266 ke Laravel API untuk memantau kepenuhan, device, sensor history, dan pengangkutan.

  • Status online atau offline dan persentase kepenuhan tiap tong.
  • Histori reading sensor dan deteksi kejadian pengangkutan.
  • Filter laporan harian, mingguan, bulanan, serta export CSV.
System scope and implementation

Scope

Dashboard menampilkan device online atau offline, tingkat kepenuhan, grafik, dan reading terbaru. Halaman tempat sampah memuat lokasi, persentase, status device, jumlah reading, serta histori pengangkutan. Laporan dapat difilter berdasarkan tanggal dan periode.

Users

Pengelola atau Admin menggunakan satu dashboard untuk memantau seluruh tong, detail sensor, status perangkat, histori pengangkutan, filter data, dan export laporan.

Implementation

ESP8266 NodeMCU dengan dua sensor HC-SR04 mengirim data melalui HTTPS POST JSON ke Laravel API menggunakan API token. Web menggunakan Laravel, MySQL, Blade, Tailwind CSS, JavaScript, dan WiFiManager untuk konfigurasi koneksi perangkat.

Output

Status kepenuhan, device monitoring, sensor history, collection event, report atau export, dan koneksi perangkat ke server.

School administration · Document workflow · 2026

Sistem administrasi persuratan untuk pencatatan surat masuk dan keluar, agenda, arsip digital, pencarian dokumen, laporan, dan manajemen pengguna.

Users

Implementation

Web information system dengan database persuratan, autentikasi, pencarian dan filter, pengelolaan file arsip, serta output laporan PDF dan DOC.

Output

Register surat, agenda, arsip digital, file dokumen, laporan administrasi, dan pengelolaan akses pengguna.
